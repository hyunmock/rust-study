변수, 가변성, 상수, 섀도잉

예상 학습 시간 20~30분

오늘의 목표

  • let으로 변수를 만들고, 기본이 불변임을 이해한다
  • mut으로 값을 바꾸는 방법을 익힌다
  • const와 섀도잉(shadowing)의 차이를 구분한다

개념 설명

Day 1에서 println!으로 글자를 출력해 봤죠? 오늘은 값을 저장하는 변수를 배웁니다. Rust의 변수는 기본적으로 불변(immutable)입니다. 한 번 값을 정하면 바꿀 수 없어서, 버그를 미리 막아 줍니다.

fn main() {
    let x = 5;
    println!("x = {x}");
    // x = 6; // 에러! 불변 변수에는 다시 대입할 수 없습니다
}

값을 바꾸고 싶다면 mut를 붙입니다.

fn main() {
    let mut count = 0;
    count += 1;
    count += 1;
    println!("count = {count}");
}

상수는 const로 선언하며, 항상 불변이고 타입을 반드시 적어야 합니다. 이름은 대문자 스네이크 케이스를 씁니다.

const MAX_POINTS: u32 = 100_000;

fn main() {
    println!("최대 점수: {MAX_POINTS}");
}

섀도잉은 같은 이름으로 let을 다시 써서 새 변수를 만드는 것입니다. mut와 달리 타입도 바꿀 수 있습니다.

fn main() {
    let spaces = "   ";        // &str
    let spaces = spaces.len(); // usize, 타입이 바뀜
    println!("공백 개수: {spaces}");

    let y = 5;
    let y = y * 2;
    {
        let y = y + 100; // 이 블록 안에서만 유효
        println!("안쪽 y = {y}");
    }
    println!("바깥 y = {y}");
}

정리: mut는 같은 변수의 값을 바꾸고, 섀도잉은 새 변수를 만듭니다. mut로는 타입을 바꿀 수 없습니다.

연습 문제

1. let mut score = 10;으로 시작해 5를 더하고 2를 곱한 뒤 출력해 보세요.

2. 문자열 "42"를 변수 n에 저장한 뒤, 섀도잉으로 같은 이름 n을 정수로 바꿔 1을 더해 출력해 보세요. (힌트: parse::<i32>().unwrap())

힌트

1번은 score += 5; score *= 2;. 2번은 let n: i32 = n.parse().unwrap(); 형태를 사용합니다.

어제 문제 풀이

풀이 보기

1. 자기소개 출력 예시:

fn main() {
    println!("이름: 헨리");
    println!("취미: 독서");
    println!("Rust를 배우는 이유: 안전하고 빠른 프로그램을 만들고 싶어서");
}

2. 세미콜론을 지우면 expected ';' 같은 메시지와 함께 줄 번호, 수정 제안이 나옵니다. 에러 메시지를 읽는 습관이 Rust 실력의 절반입니다.
