제어 흐름: if, loop, while, for

예상 학습 시간 20~30분

오늘의 목표

  • if/else if/else로 조건 분기하기
  • loop, while, for 반복문의 차이 알기
  • break, continue, 범위(..)와 반복 중 값 반환 익히기

개념 설명

어제 if가 표현식이라 값을 돌려준다는 걸 봤죠. 오늘은 이를 확장해 프로그램의 흐름을 제어하는 방법을 배웁니다. 조건은 반드시 bool이어야 하며, 숫자를 조건에 바로 쓸 수 없습니다.

1. if

fn main() {
    let n = 7;
    if n % 2 == 0 {
        println!("짝수");
    } else if n % 3 == 0 {
        println!("3의 배수");
    } else {
        println!("그 외");
    }

    let label = if n > 5 { "크다" } else { "작다" };
    println!("{label}");
}

2. loop와 break 값 반환

loop는 무한 반복이며 break로 빠져나옵니다. break 뒤에 값을 두면 loop 표현식의 값이 됩니다.

fn main() {
    let mut count = 0;
    let result = loop {
        count += 1;
        if count == 10 {
            break count * 2;
        }
    };
    println!("{result}"); // 20
}

3. while

fn main() {
    let mut n = 3;
    while n > 0 {
        println!("{n}...");
        n -= 1;
    }
    println!("발사!");
}

4. for와 범위

for는 컬렉션이나 범위를 순회할 때 가장 안전하고 많이 쓰입니다. 1..4는 1,2,3, 1..=4는 4까지 포함합니다.

fn main() {
    let a = [10, 20, 30];
    for x in a {
        println!("값: {x}");
    }
    for i in (1..=3).rev() {
        println!("카운트: {i}");
    }
    for i in 0..10 {
        if i % 2 == 0 {
            continue; // 다음 반복으로
        }
        if i > 7 {
            break;
        }
        println!("홀수: {i}");
    }
}

    if a > b { a } else { b }
}

fn main() {

    println!("{}", max_of(3, 8));  // 8
}
