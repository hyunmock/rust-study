소유권(Ownership) 1: 개념과 move

예상 학습 시간 20~30분

오늘의 목표

  • 소유권의 세 가지 규칙을 말할 수 있다.
  • move(소유권 이동)와 copy의 차이를 이해한다.
  • clone으로 데이터를 복제하고, 함수에 값을 넘길 때 소유권이 어떻게 되는지 안다.

개념 설명

Rust는 가비지 컬렉터 없이도 메모리를 안전하게 관리합니다. 비결이 소유권입니다. 규칙은 세 가지입니다.

  1. 모든 값에는 소유자(변수)가 있다.
  2. 소유자는 한 번에 하나뿐이다.
  3. 소유자가 스코프를 벗어나면 값은 버려진다(drop).

1. 스코프와 drop

fn main() {
    {
        let s = String::from("hello"); // s가 소유자
        println!("{}", s);
    } // 여기서 s가 버려지며 메모리 해제
}

2. move

String처럼 힙에 데이터를 가진 값을 다른 변수에 대입하면 소유권이 이동합니다. 이전 변수는 더 이상 쓸 수 없습니다(이중 해제를 막기 위해서입니다).

fn main() {
    let s1 = String::from("hello");
    let s2 = s1; // 소유권이 s2로 이동
    // println!("{}", s1); // 컴파일 에러: borrow of moved value
    println!("{}", s2);
}

3. clone

데이터를 정말 복제하고 싶다면 clone()을 씁니다. 비용이 들 수 있으니 필요할 때만 쓰세요.

fn main() {
    let s1 = String::from("hello");
    let s2 = s1.clone();
    println!("s1 = {}, s2 = {}", s1, s2);
}

4. Copy 타입

정수, 실수, bool, char 같은 단순 값은 스택에만 있어 대입해도 복사되고 원본도 계속 쓸 수 있습니다.

fn main() {
    let x = 5;
    let y = x;
    println!("x = {}, y = {}", x, y);
}

5. 함수와 소유권

함수에 값을 넘기는 것도 대입과 같아서 move 또는 copy가 일어납니다. 반환값으로 소유권을 돌려받을 수도 있습니다.

fn takes(s: String) {
    println!("받음: {}", s);
} // s가 여기서 drop

fn makes_copy(n: i32) {
    println!("복사됨: {}", n);
}

fn gives_back(s: String) -> String {
    s // 소유권을 호출자에게 반환
}

fn main() {
    let s = String::from("rust");
    takes(s);
    // println!("{}", s); // 에러: s는 이미 move됨

    let n = 7;
    makes_copy(n);
    println!("n은 여전히 {}", n);

    let t = String::from("again");
    let t = gives_back(t);
    println!("{}", t);
}

매번 소유권을 돌려받는 건 번거롭죠? 다음에 배울 참조와 빌림이 이 문제를 해결합니다.

연습 문제

1. 아래 코드는 컴파일되지 않습니다. 이유를 설명하고, clone을 써서 고쳐 보세요.

fn main() {
    let a = String::from("rust");
    let b = a;
    println!("{} {}", a, b);
}

2. 문자열의 길이를 계산해 (String, usize) 튜플로 문자열과 길이를 함께 돌려주는 함수 fn with_len(s: String) -> (String, usize)를 작성하고 호출해 보세요.

힌트

1번은 let b = a.clone();. 2번은 let len = s.len(); 후 (s, len)을 반환하세요.

어제 문제 풀이

풀이 보기 
fn main() {
    // 1번
    let mut sum = 0;
    for i in 1..=100 {
        sum += i;
    }
    println!("합계: {}", sum); // 5050

    // 2번
    for i in 1..=15 {
        if i % 15 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{}", i);
        }
    }
}
