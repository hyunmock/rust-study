함수, 표현식과 구문의 차이

예상 학습 시간 20~30분

오늘의 목표

  • fn으로 함수를 정의하고 호출한다.
  • 매개변수와 반환 타입을 쓴다.
  • 표현식(값을 만듦)과 구문(값을 만들지 않음)의 차이를 이해한다.

개념 설명

어제 배운 타입들은 함수의 매개변수와 반환값에 쓰입니다. Rust 함수 이름은 snake_case로 쓰고, 매개변수 타입은 반드시 적어야 합니다.

fn add(a: i32, b: i32) -> i32 {
    a + b // 세미콜론 없음: 이 값이 반환된다
}

fn greet(name: &str) {
    println!("안녕, {}!", name);
}

fn main() {
    greet("Rust");
    println!("{}", add(2, 3));
}

구문(statement)은 동작을 수행하고 값을 반환하지 않습니다(예: let x = 5;). 표현식(expression)은 값으로 평가됩니다(예: 5 + 1, 블록 { }, if). 표현식 끝에 세미콜론을 붙이면 구문이 되어 값이 사라집니다.

fn main() {
    let y = {
        let x = 3;
        x + 1 // 블록의 값
    };
    let z = if y > 3 { "크다" } else { "작다" };
    println!("y = {}, z = {}", y, z);
}

일찍 반환하려면 return을 쓸 수 있습니다. 마지막 줄에 세미콜론을 붙여 a + b;로 쓰면 반환 타입 불일치로 컴파일 에러가 납니다.

연습 문제

1. 섭씨를 화씨로 바꾸는 함수 fn c_to_f(c: f64) -> f64를 만들고 100.0을 넣어 출력해 보세요.

2. 두 정수 중 큰 값을 반환하는 fn max_of(a: i32, b: i32) -> i32를 if 표현식으로 만들어 보세요.

힌트

반환할 마지막 줄에는 세미콜론을 붙이지 않습니다. 2번은 if a > b { a } else { b }가 함수의 마지막 표현식이 됩니다.

어제 문제 풀이

풀이 보기 
fn main() {
    let c: f64 = 100.0;
    let f = c * 9.0 / 5.0 + 32.0;
    println!("{}", f); // 212

    let arr = [3, 8, 1, 9, 4];
    println!("{}", arr[0] + arr[arr.len() - 1]); // 7

    let person = ("민수", 25);
    let (name, age) = person;
    println!("{} {}", name, age);
}
