개념 설명

Day 2에서 변수를 배웠죠? 모든 값에는 타입이 있고, Rust는 대부분 알아서 추론하지만 필요하면 직접 적습니다. 정수는 i32(부호 있음), u32(부호 없음), u8, i64 등이 있고 기본값은 i32입니다. 실수는 f64(기본)와 f32입니다.

fn main() {
    let a: i32 = -42;
    let b: u8 = 255;
    let pi: f64 = 3.14159;
    let sum = a + 10;
    let div = 7 / 2;      // 정수 나눗셈: 3
    let fdiv = 7.0 / 2.0; // 3.5
    println!("{a} {b} {pi} {sum} {div} {fdiv}");
}

bool은 true/false, char는 작은따옴표로 쓰는 유니코드 문자 하나(4바이트)입니다. 한글과 이모지도 가능합니다.

fn main() {
    let is_ok: bool = true;
    let letter: char = 'R';
    let heart = '🦀';
    let han = '한';
    println!("{is_ok} {letter} {heart} {han}");
}

튜플은 서로 다른 타입을 묶고, 길이가 고정입니다. .0, .1로 접근하거나 구조 분해할 수 있습니다. 배열은 같은 타입을 고정 길이로 담으며 [타입; 개수]로 씁니다.

fn main() {
    let person: (&str, i32, f64) = ("헨리", 30, 175.5);
    println!("{} {}", person.0, person.1);
    let (name, age, height) = person;
    println!("{name} {age} {height}");

    let nums = [1, 2, 3, 4, 5];
    let zeros = [0; 3]; // [0, 0, 0]
    println!("첫 값: {}, 길이: {}", nums[0], nums.len());
    println!("{:?} {:?}", nums, zeros);
}

배열 범위를 벗어난 인덱스는 실행 중 panic이 납니다. 이것이 Rust의 안전장치입니다.

연습 문제

1. let c: f64 = 100.0;(섭씨)를 화씨로 바꿔(c * 9.0 / 5.0 + 32.0) 출력해 보세요.

2. 정수 배열 [3, 8, 1, 9, 4]의 첫 번째와 마지막 원소의 합을 출력하고, 이름과 나이를 담은 튜플도 만들어 구조 분해로 출력해 보세요.

힌트

1번은 정수 리터럴 대신 9.0처럼 소수점을 써야 f64끼리 연산됩니다. 2번 마지막 원소는 arr[arr.len() - 1]입니다.

어제 문제 풀이

풀이 보기

1. mut 변수 계산:

fn main() {
    let mut score = 10;
    score += 5;
    score *= 2;
    println!("score = {score}"); // 30
}

2. 섀도잉으로 타입 바꾸기:

fn main() {
    let n = "42";
    let n: i32 = n.parse().unwrap();
    println!("{}", n + 1); // 43
}
