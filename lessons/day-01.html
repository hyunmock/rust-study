Rust 소개, 설치(rustup), cargo new로 Hello World

예상 학습 시간 20~30분

오늘의 목표

  • Rust가 어떤 언어이고 왜 쓰는지 이해한다.
  • rustup으로 Rust를 설치하고 버전을 확인한다.
  • cargo로 프로젝트를 만들고 실행한다.

개념 설명

Rust는 C/C++처럼 빠르면서도 메모리 안전성을 컴파일 시점에 보장하는 언어입니다. 가비지 컬렉터 없이 "소유권" 시스템으로 메모리를 관리하는데, 이는 Day 6에서 배웁니다.

1. 설치

공식 도구 rustup이 컴파일러(rustc), 패키지 관리자(cargo)를 함께 설치합니다. https://rustup.rs 의 안내를 따르세요. macOS/Linux는 터미널 한 줄 명령, Windows는 설치 프로그램을 씁니다. 설치 후 확인:

rustc --version
cargo --version

2. cargo로 프로젝트 만들기

cargo new hello_rust
cd hello_rust
cargo run

cargo new는 Cargo.toml(프로젝트 설정)과 src/main.rs(코드)를 만듭니다. cargo run은 빌드 후 실행합니다.

3. Hello World 읽기

fn main() {
    println!("Hello, world!");
}
  • fn main(): 프로그램의 시작점 함수
  • println!: 느낌표가 붙은 매크로로, 한 줄을 출력
  • 문장 끝에는 세미콜론(;)

4. 값을 끼워 출력하기

fn main() {
    let name = "Henry";
    println!("안녕, {}! Rust에 온 걸 환영해.", name);
    println!("{name}님, 오늘이 Day {}입니다.", 1);
}

{} 자리에 값이 들어갑니다. 변수 이름을 {name}처럼 직접 쓸 수도 있습니다. (변수는 내일 자세히!)

5. 자주 쓰는 cargo 명령

  • cargo build: 빌드만
  • cargo check: 빠르게 컴파일 오류만 확인
  • cargo run: 빌드+실행

연습 문제

1. cargo new my_first로 프로젝트를 만들고, 자기소개 3줄(이름, 취미, Rust를 배우는 이유)을 출력해 보세요.

2. 일부러 println!("hi")의 세미콜론을 지우거나 따옴표를 빼고 cargo check를 실행해 에러 메시지를 읽어 보세요.

힌트

println!을 세 번 쓰면 됩니다. Rust 컴파일러의 에러 메시지는 친절해서 줄 번호와 해결 제안을 알려줍니다.
