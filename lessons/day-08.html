소유권 2: 참조와 빌림(&, &mut)

예상 학습 시간 20~30분

오늘의 목표

  • 참조(&)로 값을 move 없이 빌려 쓰는 법 익히기
  • 가변 참조(&mut)로 빌린 값을 수정하기
  • 빌림 규칙(가변 참조는 한 번에 하나)을 이해하기

개념 설명

Day 6에서 String을 함수에 넘기면 소유권이 move되어 원래 변수를 못 쓴다고 배웠죠. 매번 값을 돌려받는 건 번거롭습니다. 이때 참조를 쓰면 소유권은 그대로 두고 값을 빌려 쓸 수 있습니다.

fn calculate_length(s: &String) -> usize {
    s.len()
} // s는 참조일 뿐이라 여기서 값이 drop되지 않습니다

fn main() {
    let s1 = String::from("hello");
    let len = calculate_length(&s1);
    println!("'{}'의 길이는 {}", s1, len); // s1 계속 사용 가능
}

값을 고치려면 가변 참조 &mut를 씁니다. 변수도 mut여야 합니다. Day 7의 read_line(&mut input)이 바로 이것입니다.

fn add_world(s: &mut String) {
    s.push_str(", world");
}

fn main() {
    let mut s = String::from("hello");
    add_world(&mut s);
    println!("{}", s); // hello, world
}

빌림 규칙: 한 시점에 (1) 불변 참조는 여러 개 가능하거나, (2) 가변 참조는 단 하나만 가능합니다. 둘을 섞을 수도 없습니다. 이 규칙이 데이터 레이스를 컴파일 시점에 막아 줍니다.

fn main() {
    let mut s = String::from("hi");
    let r1 = &s;
    let r2 = &s;          // 불변 참조 여러 개: OK
    println!("{} {}", r1, r2);
    let r3 = &mut s;      // r1, r2를 더 이상 안 쓰므로 OK
    r3.push('!');
    println!("{}", r3);
    // let r4 = &mut s; r3와 동시에 쓰면 컴파일 에러!
}

또 참조는 항상 유효해야 합니다. 함수 안의 지역 변수에 대한 참조를 반환하는 코드(댕글링 참조)는 컴파일되지 않습니다.

연습 문제

1. fn first_word_len(s: &String) -> usize를 만들어 첫 번째 공백 전까지의 글자 수(바이트)를 반환하고, 호출 뒤에도 원래 문자열을 출력해 보세요.

2. fn shout(s: &mut String)을 만들어 문자열을 대문자로 바꾸고 끝에 "!"를 붙여 보세요.

힌트

1번은 s.find(' ')가 Option<usize>를 돌려주니 unwrap_or(s.len())을 쓰세요. 2번은 *s = s.to_uppercase(); 후 s.push('!').
