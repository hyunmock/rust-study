개념 설명

오늘은 새 개념보다 조합이 중심입니다. 게임에 쓰이는 1주차 내용은 다음과 같습니다.

  • 변수와 mut: let mut input = String::new(); 입력을 담을 가변 문자열
  • 타입: u32로 숫자를 명시
  • 함수: secret_number()가 값을 반환 (마지막 표현식)
  • 제어 흐름: for로 횟수 제한, if / else if로 크기 비교
  • 소유권: read_line(&mut input)은 가변 참조를 빌려줍니다 (자세한 내용은 Day 8)

새로 나오는 것 두 가지: input.trim().parse()는 문자열을 숫자로 바꾸려 시도하고 Ok(값) 또는 Err(오류)를 돌려줍니다. match로 둘을 나눠 처리하면, 잘못된 입력에도 프로그램이 죽지 않습니다. (match는 Day 11에서 자세히 배웁니다.)

cargo new guess_game 후 src/main.rs에 아래 코드를 붙여 넣고 cargo run 하세요. 외부 crate 없이 현재 시각으로 난수를 만들었습니다.

use std::io;
use std::time::{SystemTime, UNIX_EPOCH};

// 외부 crate 없이 간단한 난수 만들기: 현재 시각의 나노초를 이용한다
fn secret_number() -> u32 {
    let nanos = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .unwrap()
        .subsec_nanos();
    nanos % 100 + 1 // 1~100
}

fn main() {
    let secret = secret_number();
    let max_tries = 7;
    println!("1부터 100 사이의 숫자를 맞혀 보세요! (기회 {}번)", max_tries);

    for attempt in 1..=max_tries {
        println!("[{}번째] 숫자를 입력하세요:", attempt);

        let mut input = String::new();
        io::stdin().read_line(&mut input).expect("입력 읽기 실패");

        let guess: u32 = match input.trim().parse() {
            Ok(n) => n,
            Err(_) => {
                println!("숫자만 입력해 주세요.");
                continue;
            }
        };

        if guess < secret {
            println!("더 큽니다!");
        } else if guess > secret {
            println!("더 작습니다!");
        } else {
            println!("🎉 정답! {}번 만에 맞혔어요.", attempt);
            return;
        }
    }
    println!("아쉽네요. 정답은 {} 였습니다.", secret);
}

연습 문제 (미니 과제)

1. 기회를 7번 대신 5번으로 줄이고, 남은 기회를 매번 출력해 보세요.

2. 범위를 1~50으로 바꾸고, 정답과의 차이가 5 이하이면 "거의 다 왔어요!"를 추가로 출력해 보세요.

힌트

1번은 max_tries 값과 max_tries - attempt를 쓰세요. 2번은 nanos % 50 + 1, 그리고 차이는 guess.abs_diff(secret) <= 5로 구할 수 있습니다.
